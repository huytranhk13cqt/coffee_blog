# Project Vision

> **Document Type**: Strategic Vision
> **Project**: Coffee's Personal Blog CMS
> **Version**: 1.0
> **Last Updated**: 16/12/2024

---

## 1. Project Overview

### What is this project?

A **personal blog and portfolio website** built from scratch to:
1. Showcase technical writing and projects
2. Learn full-stack web development
3. Create a unique "Cozy Pixel Cafe" brand identity

### One-Line Description

> "A cozy, pixel-art styled personal blog where Coffee shares tech articles, life stories, and creative projects."

---

## 2. Vision Statement

### The Dream

```
"To create a personal digital space that feels like a warm corner
in a cozy cafe - where visitors can read interesting articles,
explore creative projects, and get to know the person behind the code."
```

### Success Looks Like

In 6 months, this blog will:
- [ ] Have 20+ published articles
- [ ] Showcase 5+ portfolio projects
- [ ] Have a unique, memorable design
- [ ] Be fully functional for content management
- [ ] Serve as a learning portfolio for job applications

## 3. Target Audience

### Primary Audience

| Who | Why they visit | What they want |
|-----|----------------|----------------|
| **Tech recruiters** | Evaluate skills | See projects, read technical articles |
| **Fellow developers** | Learn/share knowledge | Read tutorials, see code examples |
| **Friends/Family** | Personal connection | Read life updates, see what I'm working on |

### Secondary Audience

| Who | Why they visit |
|-----|----------------|
| **Design enthusiasts** | Appreciate the pixel art aesthetic |
| **International students** | Relate to shared experiences |
| **Retro gaming fans** | Enjoy the GBA-inspired style |

## 4. Core Values

### Design Values

| Value | Meaning | How it shows |
|-------|---------|--------------|
| **Cozy** | Warm, inviting, comfortable | Warm colors, soft interactions |
| **Pixel Art** | Nostalgic, handcrafted, unique | GBA-inspired sprites and UI |
| **Personal** | Authentic, not corporate | Coffee theme, mascots, personal voice |
| **Simple** | Easy to navigate, not overwhelming | Clean layout, clear hierarchy |

### Development Values

| Value | Meaning |
|-------|---------|
| **Learn by doing** | Build everything from scratch |
| **Document everything** | Write down what you learn |
| **MVP first** | Working features before polish |
| **Iterate** | Improve continuously |

## 5. Brand Identity

### Name & Theme

- **Brand**: Coffee's Blog
- **Theme**: Cozy Pixel Cafe
- **Tagline**: "Brewing thoughts, one post at a time"

### Visual Identity

```
Color Palette:
├── Primary: Warm browns (#865A3B)
├── Background: Cream (#FDFBF3)
├── Accent: Golden yellow (#FFD700)
└── Dark mode: Espresso (#1A1814)

Typography:
├── Display: Silkscreen (pixel font)
└── Body: IBM Plex Sans (readable)

Style:
├── Pixel art sprites and icons
├── GBA-era aesthetic
└── Warm, cozy atmosphere
```

### Mascot/Character

- Developer character (pixel art, 32x32)
- Bulbasaur companion (representing growth)
- Coffee cup with steam (brand symbol)

## 7. Non-Goals (Out of Scope)

Things this project is **NOT** trying to be:

| Not This | Why |
|----------|-----|
| Multi-user platform | Personal blog, single author |
| E-commerce site | No products to sell |
| Social network | Not building community features |
| News aggregator | Original content only |
| Mobile app | Web-first, responsive design |

## 8. Success Metrics

### MVP Success (Phase 1)

- [ ] Can create a new post from admin UI
- [ ] Can edit existing posts
- [ ] Can publish/unpublish posts
- [ ] Authentication works (only owner can edit)
- [ ] All public pages functional

### Long-term Success

| Metric | Target |
|--------|--------|
| Page load time | < 3 seconds |
| Mobile usability | Works on all devices |
| Content | 20+ articles |
| Uptime | 99% availability |

## 10. Key Questions Answered

### Why build from scratch?

> To learn full-stack development deeply, not just use templates.

### Why this design style?

> Combines two things I love: retro gaming and cozy cafes.

### Why React + FastAPI?

> Modern, industry-relevant stack with good documentation.

### Why Supabase?

> PostgreSQL power with easy setup, auth, and storage built-in.
